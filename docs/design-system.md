# Detsbee Design System

## Colors

| Token | Value | Use |
|-------|-------|-----|
| honey-300→500 | `#F0C453` → `#D9A21A` | Brand accent, CTAs |
| ink-950/900 | `#0C0B09` / `#14120F` | Dark surfaces, play UI |
| cream / cream-soft | `#F7F1E6` / `#FBF7F0` | Creator canvases |
| ink-500/600 | neutrals | Secondary text |

## Typography

- **Display:** Fraunces  
- **UI:** Manrope  
- Scale: large display headlines, comfortable body 16–18px  

## Spacing & radius

- Base spacing: 4px grid  
- Radii: 1.25rem controls, 1.75–2.25rem panels  
- Buttons: pill (`999px`)

## Components

- `.db-btn-primary` honey gradient CTA  
- `.db-btn-ghost` quiet outline  
- `.db-glass` cream glass panels  
- `.db-dark-panel` play/creator hero panels  
- `.db-input` soft focused fields  
- `.db-chip` honey meta labels  

## Motion

- Page/phase fade + slight translate (~160–550ms)  
- Trail progress width animation  
- Prefer ease over bounce  

## Breakpoints

Mobile-first play max-width `32rem`; creator shell `1120px`.
